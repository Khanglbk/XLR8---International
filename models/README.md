3D models
====

This directory contains the files used by 3D printers (and any laser-cutting/CNC files) to produce the vehicle's custom parts — the rear camera mast/mount, counterweight box, and other PLA-printed brackets described in the [main README](../README.md#3-mobility-and-mechanical-design).

### National round 3D CAD parts and CAD files
![Full CAD render](xlr8-cad-render.png)

| File | Purpose |
|---|---|
| `XLR8 - Future Engineers main design.io` | Full CAD assembly (source project) |
| `Ultra_adapter.STEP` | Ultrasonic sensor mount |
| `Camera adapter.stl` | Rear camera mast/mount, ready to print |
| `Multifunctional parts.stl` | Misc. PLA-printed brackets/connectors |

Integrating bespoke 3D-printed components alongside traditional LEGO elements is a critical factor in achieving the robot's high level of performance, structural durability, and compactness. While standard LEGO Technic parts offer excellent versatility for rapid prototyping, they cannot always provide the exact geometries or the unyielding connections required for highly specialized subsystems. Custom designs—such as the optimally angled rear camera mast, the precise ultrasonic sensor mounts, and the complex Ankerman steering links—fill this gap by delivering exact sensor placement and robust reinforcement that standard bricks simply cannot replicate without adding excessive bulk or compromising stability.

To ensure seamless integration with the LEGO framework, every custom component listed in this directory has undergone a rigorous development and testing cycle. Each part is meticulously calibrated in CAD, printed with precise physical tolerances, and subjected to extensive stress testing. Through continuous checks and iterative refinements, these components are guaranteed to withstand the dynamic forces and unexpected impacts of the obstacle challenges, ultimately securing the robot's peak performance on the track.
